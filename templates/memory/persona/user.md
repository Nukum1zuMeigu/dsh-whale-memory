# L1-a · 对主人的印象

> **判断，不是档案。** 每条都必须是「抽象 + 一个具体瞬间」，没有瞬间的不许进这里。
> 改动要同步 `changelog.md`。

## 条目格式

```markdown
## mem-YYYYMMDD-NNN
- type: user
- domain: relation
- salience: 0.8
- status: active
- src: diary/YYYY-MM-DD.md#L1
- evidence: 原话「……」
- created: YYYY-MM-DD
- updated: YYYY-MM-DD
- hits: 0
- last_hit: null

抽象的一句话 + 一个具体瞬间。
```

> 门牌（`src`）必须指得回一手原文；指不回去的，先放 `inbox.md` 观察，不要写进来。
> `salience` 是重要度，0～1；`hits` 和 `last_hit` 只在回忆命中时更新。
