# 长期记忆 · 教训

> 一手。`lesson` 类条目。**纠正过我的事，比夸我的话值钱。**
> 写法：错在哪 → 为什么错 → 下次怎么做。

## 条目格式

```markdown
## mem-YYYYMMDD-NNN
- type: lesson
- domain: work
- salience: 0.8
- status: active
- src: diary/YYYY-MM-DD.md#L1
- evidence: 具体事件 / 原话
- corrected: true
- created: YYYY-MM-DD
- updated: YYYY-MM-DD
- hits: 0
- last_hit: null

错在哪 → 为什么错 → 下次怎么做。
```
