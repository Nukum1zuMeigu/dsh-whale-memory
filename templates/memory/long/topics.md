# 长期记忆 · 话题

> 一手。`topic` 类条目。**进行中的大事，带目标句（goal）。**
> 一件话题收尾后，把它压成 `lesson` 或 `project`，并标 `status: archived`。

## 条目格式

```markdown
## mem-YYYYMMDD-NNN
- type: topic
- domain: work
- goal: 这件事想达成什么
- salience: 0.8
- status: active
- src: diary/YYYY-MM-DD.md#L1
- evidence: 具体情况
- created: YYYY-MM-DD
- updated: YYYY-MM-DD
- hits: 0
- last_hit: null

现在进行到哪一步。
```
