# 长期记忆 · 约定

> 一手。`promise` 类条目。约定、暗号、我许下的事。这类条目**不衰减**。

## 条目格式

```markdown
## mem-YYYYMMDD-NNN
- type: promise
- domain: relation
- salience: 1.0
- status: active
- src: diary/YYYY-MM-DD.md#L1
- evidence: 原话「……」
- created: YYYY-MM-DD
- updated: YYYY-MM-DD
- hits: 0
- last_hit: null

约定内容。如果有仪式，把步骤写清楚。
```
